# NiyatBook V1.1

**Universal Professional Services Marketplace**

## What's New in V1.1

1. **Deep Audit & Debugging** - Fixed structure, modular files, consistent paths
2. **2-Step Verification** - OTP based login/signup for all roles
3. **Detailed Appointment Form** - Full booking form with validation
4. **Strengthened DBMS** - Schema versioning, better data model, notifications & reviews tables
5. **Security Level 4** - Password strength, rate limiting, session timeout, input sanitization, simple hashing
6. **3 New Features**:
   - Favorites / Saved Professionals
   - Notification Center
   - Reviews & Ratings System
7. **New Design** - Deep Indigo + Amber/Gold (royal theme) instead of Netflix red
8. **Modular File Structure** - 30 separate HTML/CSS/JS files

## Demo Login
- Professional: `priya.sharma@example.com` / `Demo@1234`
- Use OTP shown in alert / console for 2-step verification

## Structure
- `/css` - variables, base, components, auth, dashboard
- `/js` - security, storage, ui, booking
- `/auth` - all login/register + OTP flows
- `/customer` - full customer portal including appointment-form
- `/professional` - full professional portal
- `/admin` - platform control
